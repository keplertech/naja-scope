# naja-scope 0.2.0 candidate

Requires **najaeda 0.7.35 or newer**. The optional schematic extra requires
**naja-schematic >=0.3.0,<0.4**. This candidate has not been published.

## Breaking MCP path contract

Every hierarchical path is now a JSON list of exact names. String paths are
rejected, with no compatibility parser. The top name is optional. Bus indices
use a separate `bit` field; brackets inside a name stay literal.

```python
resolve(path=["u_core", "d_in"], bit=0, kind="term")
resolve(path=["u_core", "d_in[0]"], kind="term")  # literal scalar name
find(pattern=["**", "*state*"], kind="net")
```

Resolution walks one element per level, without splitting, unescaping or
rejoining names. `["a.b"]` and `["a", "b"]` select different occurrences.
Errors identify the failing element's index and value, its parent, and close
matches at that level. Patterns apply fnmatch to individual names; `"**"`
provides recursive descent.

Path descriptors return `path`, `bit`, and `kind` for safe round trips through
`resolve`. Hierarchy, source, intent, connectivity, cones, schematic selection,
and schematic targets use structured paths. Cone subtree groups are lists of
records rather than mappings keyed by strings. Leaf connectivity endpoints
retain instance paths; `pin_bit` and `queried_bit` identify pin and seed bits.

Schematic exports use lists of name lists for instances and `{path, bit}`
records for nets and traces. MCP schemas expose these nested structures.
Intent references are lists too, including `["pkg::NAME"]` and `["pkg"]`.
Model names and filesystem paths remain strings.

See [migration examples](../paths.md) and the [changelog](../../CHANGELOG.md).

## Validation

The complete local suite passes **207 tests, 0 failed, 0 skipped**, including
all three CVA6 regressions against a freshly saved and reloaded RV32 snapshot.
The existing shared snapshot cache was preserved. Coverage includes escaped
Verilog names, dotted VHDL generate labels, ambiguous hierarchy splits,
scalar bracket names versus bus bits, punctuation and spaces, path round
trips, indexed errors, input rejection, and nested MCP schemas.

Both bundled UART and gate-level walkthroughs pass. See
[validation details](../validation/structured-paths.md) for the isolated
snapshot command and upstream CVA6 recheck. CVA6 remains pinned to v5.3.0
(`2ef1c1b1fca419354920c5487293bc605294904e`); the upstream master revision and
issue #3594 are unchanged from the prior najaeda 0.7.35 validation.

Wheel and sdist build successfully and both pass `twine check`.
Runtime and MCP Registry metadata agree on 0.2.0. No tag, package publication,
or MCP Registry submission is part of this candidate PR.
