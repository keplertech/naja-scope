# naja-scope 0.1.25 candidate

Requires **najaeda 0.7.35 or newer**. This candidate has not been published.

## Smaller MCP responses

MCP tools return compact JSON together with structured output. `get_stats()`
returns summary statistics by default; request model details with `limit` and
follow `next_cursor` to paginate. Default `find`, `get_drivers`, and `get_loads`
pages now contain at most 20 entries. Explicit limits remain available.

## Search and intent navigation

`find` explains unsupported regex-style patterns and suggests glob syntax.
When a search matches a parameter declaration, it suggests a working
`get_intent` call while the source intent link is available.

SystemVerilog intent queries accept instance-qualified parameter paths such as
`uart_top.u_tx.DIV_W`, package names, and package-qualified members. Package
candidates from source files and includes are checked against the live engine;
inactive declarations are excluded. VHDL package navigation remains covered
by regression tests.

## Installation and examples

README install buttons configure VS Code and Cursor, and the MCP Registry
metadata includes the project website, icon, and `uvx` runtime hint. The
CORE-V-MCU demo explicitly requests model statistics under the new summary
default. CI no longer runs the Intel macOS source-build lane.
