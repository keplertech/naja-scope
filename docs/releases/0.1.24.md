# naja-scope 0.1.24 candidate

Requires **najaeda 0.7.35 or newer**. This candidate has not been published.

## Content comparison

New read-only MCP/Python query `get_content_hash(module=None)` returns the
native SHA-256 of the top model, or a named elaborated model, including its
descendants. The response carries the hash format version and naja commit.
Hashes survive snapshot reload and reflect descendant wiring changes.
Computation is on demand, with no persistent cache or added module-card cost.

Names and IDs participate. Source metadata and primitive definitions are
excluded. Compare only within the same format version and track the engine
separately when primitive semantics matter; this is not functional equivalence
checking.

## Engine upgrade

The published 0.7.35 wheel (`c7ebdfc4f9f580684bf93998fcdc88e3009f2498`)
adds raw timing/clock-domain queries, generated-clock handling, explicit reset
domains, and content hashing. This candidate exposes hashing. Timing/reset
analysis remains available through raw naja, pending a separately designed,
bounded naja-scope interface with explicit user constraints.
