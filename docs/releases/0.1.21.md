# naja-scope 0.1.21

This version requires **najaeda 0.7.33 or newer**, which fixes the nested
packed-array write regression affecting CVA6 RV32 elaboration.

## Improvements

- SystemVerilog loading accepts `default_timescale`, such as `1ns/1ps`, for
  modules without explicit time units. The setting is preserved in snapshots
  and reused when loading design intent.
- Memory cards report `address_bits` and `reset_mode` using native memory
  interfaces. Instance dimension overrides are honored, and unused ports
  remain included in declared port counts.
- VHDL source cross-probing covers entities, ports, signals, instances and
  inferred register processes, including after snapshot reload.
- Gate-level loading uses najaeda's explicit `loadGateLevelVerilog` API,
  avoiding the deprecated loader warning. The public `load_verilog` tool
  keeps its existing name and behavior.
- Source distributions include the fixtures, metadata and benchmark files
  required by the bundled test suite.

## Snapshot migration

Rebuild snapshots created with najaeda 0.7.30 (schema 0.2.0). Najaeda 0.7.33
uses schema 0.3.0; old snapshots are not compatible. Re-elaborate the source
with the appropriate loader, then call `save_snapshot` to create a new cache.

## CVA6

CVA6 v5.3.0 remains the supported demo and regression baseline. Both
`cv32a6_imac_sv32` and the default `cv64a6_imafdc_sv39` configuration elaborate
with the published najaeda 0.7.33 wheel. Fresh RV32 snapshot reload and all
three CVA6 regressions pass. Current CVA6 master still has three known
elaboration failures; its revision is not promoted.

See [validation details](0.1.21-validation.md) for exact revisions and results.
