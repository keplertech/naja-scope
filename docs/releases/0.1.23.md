# naja-scope 0.1.23 candidate

Requires **najaeda 0.7.34 or newer**. This candidate has not been published.

## VHDL

- `get_intent` answers for VHDL through `load_vhdl(intent=True)`,
  `NAJA_SCOPE_INTENT=1`, `load_intent` and `load_snapshot(intent=True)`. It
  returns enum literals, record fields, generics, constants and symbolic ranges
  in the SystemVerilog record shape. Enums held in record fields are reported,
  and `want="fsm_states"` accepts such a record.
- `load_vhdl(library=...)` compiles into the library a design names. Snapshots
  and `load_intent` keep it.
- VHDL instance parameter lists leave out package constants and report
  `package_constants_omitted`. Use `pkg::NAME` for those.

## Fixes

- Paths resolve through instance names that contain dots, which VHDL generate
  labels produce. Everything under such an instance was unreachable by path in
  all tools.
- `load_intent` checks the source files exist before it destroys the universe,
  so a snapshot with moved sources keeps its design. An `flist` is checked
  itself, not the files it lists.

## Validation

[NEORV32](https://github.com/stnolting/neorv32) `ca86862`, with published
najaeda 0.7.34 and `rtl/file_list_core.f`, elaborates `neorv32_top` at default
generics in 1.4 s on the raw and public APIs: 18 hierarchical instances, intent
retained. Checked by hand against the source: `exec` in `neorv32_cpu_control`
is 117 bits with the 11-state, 4-bit `exec_state_t`; `exc_buf` keeps
`exc_width_c-1 downto 0`; `neorv32_package::mem_io_size_c` is 2097152 from
`32 * mem_io_dev_size_c`; `bus_req_t` is 82 bits. Drivers, loads, cones, `find`
round trips and an intent snapshot reload work on paths through
`core_complex_gen[0].core_complex_inst`. Only default generics were exercised.

CVA6 v5.3.0 (`2ef1c1b1fca419354920c5487293bc605294904e`) `cv32a6_imac_sv32`
passes all three regressions against a fresh snapshot. The suite passes 151
tests with none skipped.

Limits: enum and record bit positions within a record are not reported, because
naja gives no field offsets; inferred flops have no source symbol; packages no
elaborated design uses cannot be found; `expr` for an overridden generic is its
default.
